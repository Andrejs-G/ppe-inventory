# PPE Inventory

Offline PPE store app for the ship: stock, issues and receipts, stock counts, quarterly order proposal, Excel export.

Open https://andrejs-g.github.io/ppe-inventory/ once with internet. On iPhone: Safari → Share → Add to Home Screen. After that it works without internet.

No inventory data is stored here. Data lives in your own "PPE data" file; crew members load a "store package" file and send back an "issues" file.

## Paint Inventory

Paint store app (stock in litres, use and receipts, monthly counts, order proposal, vessel paint chart, RAL colours, Excel export): https://andrejs-g.github.io/ppe-inventory/paint/

Same idea: no data stored here. Open your own "Paint data" file in the app; the paint chart travels inside that file.
